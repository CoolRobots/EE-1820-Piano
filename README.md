Instructions to run project:

Make a new project in this chuddy website: https://stepfpga.eimtechnology.com
set all of the pinouts (18 ins for the keys, 8 for each 7-seg display, 8 outs for the DAC (8-bits!)
get the website to make you a file (hopefully it works)
Plug in the Step FPGA-Core board and drag the file into it like a USB-Drive
Wire it up as shown in the Wiring.png


Troubleshooting:
When the website inevitably decides not to work try these things
Make new project
Make a new account
Use a different browser
Use a different computer
